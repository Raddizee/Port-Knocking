Topologi Port Knocking + SSH Key Authentication

Proteksi ganda pada manajemen router — jaringan tersembunyi, autentikasi tanpa password

Belum terautentikasi Proses port knocking Akses diizinkan
1

Port SSH tertutup

Port 22 diblokir default oleh firewall, tampak filtered saat di-scan dari luar.

2

Urutan ketukan

Klien mengirim paket ke port 7000 → 8000 → 9000 secara berurutan dan benar.

3

IP masuk whitelist

Firewall menambahkan IP klien ke address-list ssh-allowed dengan timeout singkat.

4

Autentikasi SSH Key

Login hanya diterima dengan kunci privat yang cocok; login password dinonaktifkan.
